# NestJS Social Media

**full social media real time chat** built with Node.js, NestJS and more...

## FEATURES

- Watch and share Posts and Reels
- Write Comments under Posts and Reels
- Like Posts and Reels
- Message anyone you want
- Follow anyone you want
- Anyone can follow you
- Chat with your friends
- Have fun!

## TECHNOLOGIES

- **Node.js** - JavaScript runtime
- **NestJS** - Web Framework
- **TypeORM** - SQL Database orm
- **PostgreSQL** - Database
- **JWT** - Authentication
- **multer** - uploading files
- **cookie-parser** - parsing cookies
- **bcryptjs** - hashing users password in DB
- And much more...
